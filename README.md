# Yachdav Management System

An academic team project developed to support fleet and maintenance operations at Yachdav, a nonprofit organization.

The project connects organizational requirements with a working Windows desktop application, using C#, .NET 8 WinForms, and Azure SQL.

## Main Features

- Fleet management, vehicle checkout, and return approvals.
- Maintenance ticket creation, assignment, and status tracking.
- Daily, weekly, and monthly maintenance calendars.
- Employee workload visibility and scheduling conflict prevention.
- Automatic creation of preventive maintenance tickets based on predefined dates.
- Payment request submission and approval workflows.
- Dedicated home screens and actions for different organizational roles.
